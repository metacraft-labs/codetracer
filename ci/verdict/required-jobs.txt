# Jobs that MUST execute on every push / pull_request run of
# .github/workflows/codetracer.yml.
#
# "Execute" means the job reached a conclusion of `success` or `failure`.
# A job that is `skipped` or `cancelled`, or that is missing from the
# workflow entirely, means this commit lost the coverage that job provides —
# ci/verdict/required-jobs.sh reports that as "CI DID NOT RUN THE TESTS"
# rather than letting it hide inside an ordinary red run.
#
# ONLY list jobs that are expected to run unconditionally. Jobs carrying an
# `if:` that legitimately suppresses them (nightly schedules, tag-only
# publishes, branch-scoped deploys) must NOT appear here, or this gate would
# cry wolf on every normal run:
#   origin-dap-windows-nightly, origin-dap-macos-nightly  (schedule/dispatch)
#   publish-pypi, create-release                          (tag-only)
#   push-to-attic, build-and-deploy-docs                  (main-only)
#
# Pure publication side-effects (push-gpg-public-key, push-install-script,
# push-tag) are also omitted: they ship artifacts, they do not provide test
# coverage, and their failures are already visible as ordinary job failures.
#
# Every name here must match a job *id* in .github/workflows/codetracer.yml
# (the key under `jobs:`), not its display name. Matrix jobs collapse to a
# single result under their job id in the `needs` context.
