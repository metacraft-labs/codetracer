# db-backend integration tests the Windows `windows-headless-test` lane does
# NOT provide the tools for.
#
# That lane runs ci/test/windows-headless-tests.sh: the DAP tests (`test(~dap)`)
# with CODETRACER_ALLOW_GRACEFUL_TEST_SKIPPING=false, so a test whose
# prerequisite is missing there FAILS. The tests below are excluded by name and
# printed as NOT RUN with the lane that runs them.
#
# What the lane provides: env.ps1's toolchain (Rust/MSVC, nim/nimble, capnp,
# node/npx, nargo, go, gcc/g++/gdb), the db-backend siblings, and `ct_mcr.exe` +
# `ct_interpose.dll` built from codetracer-native-recorder. TTD validation is
# switched off (WINDOWS_DIY_ENSURE_TTD=false) and ct-native-replay is not
# built, so the TTD tests run in windows-rust-components instead.
#
# The interpreted-language, WebAssembly and blockchain recorders are not
# supported on Windows (Language-Support-Matrix.md); their DAP tests run on
# Linux. Lean has no Windows toolchain path.
#
# Format and checks: as in non-gui-not-provided.linux.txt
# (ci/test/lane-not-provided-test.sh).
