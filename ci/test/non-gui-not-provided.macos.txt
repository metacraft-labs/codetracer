# Integration tests (db-backend and backend-manager) the macOS `test-non-gui`
# lane does NOT provide the tools for.
#
# The macOS leg runs `just test-rust` with CODETRACER_ALLOW_GRACEFUL_TEST_SKIPPING=false,
# exactly like the Linux leg (see non-gui-not-provided.linux.txt for the
# mechanism), so a test whose prerequisite is missing there FAILS.
#
# What the leg provides, enumerated from the `test-non-gui` job, the aarch64-darwin
# dev shell (`nix develop .` = nix/shells/main.nix over ci-base.nix) and its
# runner label (`aarch64-darwin`, the m3 nix-darwin hosts):
#
#   - siblings, cloned and built in the job: codetracer-trace-format (+ -nim and
#     `ct-print`), codetracer-native-recorder (the MCR emulator the db-backend
#     build links; `ct-mcr` itself is NOT built), codetracer-python-recorder
#     (the dev shell's recorder venv), codetracer-ruby-recorder (native
#     extension), codetracer-beam-recorder, codetracer-js-recorder,
#     codetracer-wasm-instrumenter (`ct-instrument`);
#   - from the dev shell: cargo + the wasm32-wasip1 / wasm32-unknown-unknown
#     targets, wazero, nargo, circom, cargo-stylus, node / npx, black, ruby,
#     python, go, gcc / clang, nim.
#
# Not on this leg, and the tests that need them:
#
#   - `ct-mcr` / `ct-native-replay`: the MCR flow tests and the backend-manager
#     tests that record with `ct-mcr` (run on Linux in mcr-dap-flow). Of the
#     latter only meta_dat_real_mcr_recording's recording test is compiled on
#     macOS; real_recording_integration's goto_geid test is Linux x86_64 only;
#   - rr: Linux-only. The rr flow tests (go/lean/nim/rust_flow_integration) and
#     origin_rr_smoke are compiled only on Linux/Windows, so they are not in
#     this list; the `rr::` origin tests are excluded by `just test-rust`
#     (CODETRACER_RR_BACKEND_PRESENT=0). backend-manager's rr tests in
#     real_recording_integration ARE compiled here, and fail without the
#     codetracer-native-backend checkout and rr, so they are listed below;
#   - the blockchain and PHP recorders, and forc / cargo-build-sbf, which the
#     dev shell ships only on Linux (nix/shells/main.nix): the recorder-tests
#     lane;
#   - the shell recorders (Bash, Zsh): the recorder-tests lane.
#
# Format and checks: as in non-gui-not-provided.linux.txt
# (ci/test/lane-not-provided-test.sh).
