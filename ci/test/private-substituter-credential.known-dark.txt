# Consumers that are handed this org's PRIVATE Attic substituter and cannot be
# given a credential for it here, because the action on the other end has no
# code path that writes one.
#
# This is a register, not a waiver.  A step listed here still reads the private
# cache ANONYMOUSLY, still gets 401 from `nix-cache-info`, and still builds from
# source everything that is not on cache.nixos.org.  What being listed buys is
# that the condition is stated instead of silent, and that the scanner fails if
# an entry stops being true in either direction -- a new unregistered consumer,
# or a stale entry no step hands a substituter to any more.
#
# HOW A CONSUMER LEAVES THIS FILE: the action it names grows the same thing
# `metacraft-labs/metacraft-github-actions/setup-nix` grew in `03056f3` -- an
# `attic-token` input written into the netrc that nix.conf's `netrc-file` names
# (see that repo's `setup-nix/write-nix-netrc.sh`).  Then the callers pass
# `attic-token: ${{ secrets.ATTIC_TOKEN }}` and the entry is deleted.
#
# Format: one consumer reference per line (no `@ref`), `#` starts a comment.

# Wraps `metacraft-labs/devops-modules/.github/setup-nix`, below.  Nothing is
# gained by threading a token through this wrapper until the action it wraps can
# use one, and threading it anyway would look like the fix without being it.
./.github/actions/setup-nix

# `.github/setup-nix` in that repo writes `netrc-file = $HOME/.config/nix/netrc`
# and then writes that netrc through its own `write-netrc.sh`, which files ONE
# machine -- github.com.  Its `attic-token` input feeds only `attic login`,
# which configures the Attic CLI for UPLOADING and writes nothing nix reads.
# So a token passed here is inert for substitution, which is the half that is
# missing.  Fixing it is a change in devops-modules, not in this repository.
metacraft-labs/devops-modules/.github/setup-nix

# `.github/install-nix` is a symlink to `.github/setup-nix` in the same repo, so
# it is the same action and the same gap.
metacraft-labs/devops-modules/.github/install-nix
