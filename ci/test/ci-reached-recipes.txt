# `just` recipes that a CI WORKFLOW LANE must reach.
#
# Read by `ci/test/ci-reached-recipes-test.sh`, which fails, by name, on any
# recipe listed here that the reachability walk in
# `ci/test/shell-gate-coverage.sh` does not reach from `.github/workflows/`.
# "Reach" is that walk's rule: a workflow step invokes the recipe, or a recipe or
# script a reached step invokes does. A remedy message that names the recipe in a
# string is not a call that runs it.
#
# WHAT BELONGS HERE. A recipe that is the ONLY route to a body of tests, so that
# no lane calling it means those tests run nowhere -- and nothing else fails,
# because `shell-gate-coverage.sh` measures scripts, not recipes, and
# `test-lane-coverage.sh` asks whether a Nim file is IN a lane, not whether a
# workflow RUNS that lane.
#
# WHAT DOES NOT. The other recipes no lane reaches today. Most are things a
# person types, and the walk cannot tell those from a lane somebody forgot.
# Each entry is a decision that a lane runs the recipe, made where the spec
# governing those tests says so, and recorded here so it cannot be undone
# silently. Adding a recipe means wiring it in the same change, or this file's
# test is red.
#
# Format: one recipe name per line, then `#` and why it must be reached.
# Blank lines and `#` lines are ignored.
