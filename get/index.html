Install CodeTracer

One command, any shell. The script is served as plain text — read it before you run it.

Linux · macOS · WSLDetected

curl -fsSL https://get.codetracer.com/sh | sh

On Debian, Ubuntu, Fedora and RHEL this adds the Metacraft Labs package repository (deb.metacraft-labs.com, rpm.metacraft-labs.com) and installs the codetracer package, so updates come with apt upgrade or dnf upgrade. Arch installs from the AUR, Gentoo from metacraft-overlay, macOS from the release DMG.

Pin a version: curl -fsSL https://get.codetracer.com/sh | sh -s -- --version 26.09.1

Windows · PowerShellDetected

irm https://get.codetracer.com/pwsh | iex
